# 无人装备战争游戏仿真系统

Python + PySide6/QML 二维桌面仿真。保留五类单位、地图编辑、侦察与目标共享、交战状态机、同步伤害结算和统计，按课程验收优化操作流程。仿真参数为教学抽象值。

## 使用流程

选择“标准对抗 / 障碍环境 / 自定义场景 / 山区河谷 / 河谷城镇” → 浏览地图、编辑部署 → 保存或另存为 → 开始仿真 → 暂停、单步、变速、点击单位查看详情 → 自动结算 → 返回战场、重新运行或修改部署。

- 全界面统一使用随程序提供的思源宋体，包含常规与粗体；中文、数字、地图标签和兼容入口共享同一字体，无需在系统中安装。字体来源与许可证见 [字体记录](ui/assets/fonts/sources.json) 和 [SIL OFL 1.1](ui/assets/fonts/LICENSE.txt)。
- 图形界面提供主要操作，快捷键作为辅助。采用简洁深色地图工作台，统一主次操作、键盘焦点与紧凑侧栏；设计依据及同场景对比见 [界面优化与产品参考](docs/界面优化与产品参考.md)。
- 山区河谷与河谷城镇使用“应用综合实验”的原图素材，配有地标、矩形通行约束与桥梁通道；代码仍沿用本项目内核、控制器和 QML 结构。
- 滚轮缩放、中键拖动地图，右下小地图可点击或拖动定位；顶部可适应地图、开关网格、地标及全部单位范围。单位图标随缩放调整，选中或放大后显示详细标签。
- 部署时可选战术、山谷或河谷背景，背景选择随 JSON 场景保存；图片用于展示，实际通行仍以高亮矩形及现有单位规则为准。
- 点选单位查看生命、弹药、速度、探测范围与交战阶段，战场同步高亮。
- “快速计算”以短批次推进，界面按约 30 次/秒刷新，适合快速获得结果。
- 结算区分攻击发起和命中次数，记录单位与基地的摧毁步数、累计仿真时间及击毁来源，可导出 JSON 结果。
- “运行记录”分类查看侦察、目标共享、摧毁、战术状态与结果；界面显示最近 200 条，导出和自动保存保留全部记录。暂停、结算、重跑及返回部署时保存本局，历史记录存入用户目录 `runs`。
- “再来一局”恢复本次开跑前的部署并清理旧局选择；运行后的“返回部署/重置”也恢复该部署供修改。
- 内置预设只读，自定义场景默认保存到用户目录。
- “时间设置”可在部署或暂停时修改单步时长（0.01–60 秒）与最大运行步数（1–10,000）；默认 0.22 秒、2000 步。暂停后的上限须大于已运行步数，到上限仍未分胜负则结算平局。当前完整运行记录采用内存保留与原子保存，因此设置了有界上限。

## 安装与启动

使用 Python 3.10 或以上，建议 3.11。在项目根目录执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

已安装依赖时可直接运行 `python main.py`。主入口是 QML 前端；`python pygame_main.py` 保留兼容前端。

Windows 单文件程序由构建脚本生成至 `dist/UAV_WarGame.exe`，双击启动，无需另装 Python。源码仓库不提交生成的 EXE；也可手动触发 GitHub Actions，在成功运行的产物中下载程序。本轮已完成 Windows 11 本机 EXE 工作流自检；独立电脑及显示缩放检查见测试报告。

## 场景与结果文件

- 标准场景：`data/scenario_1.json`；另提供障碍环境、空白自定义场景，以及 `scenario_valley.json`（山区河谷）和 `scenario_river_city.json`（河谷城镇）。两张新地图均为 1200×800，各有 14 个单位、16 个障碍。
- Windows 用户数据根目录：`%LOCALAPPDATA%\UAV_WarGame`，场景位于其下 `scenarios`，每局运行记录位于 `runs`。
- `保存`：写入当前自定义文件；首次默认写入用户目录 `saved_map.json`。
- `另存为`：选择新的 JSON 文件，随后 `保存` 继续写入该文件。
- `载入地图…`：加载成功进入部署，失败保留原场景并提示原因。
- 导出结果或分类运行记录由用户选择路径；内置资源和 PyInstaller 临时目录不用于保存用户数据。
- 测试及便携环境可设置 `UAV_WARGAME_DATA_DIR` 指定数据根目录。

## 操作速查

| 操作 | 快捷键 |
| --- | --- |
| 开始 | Enter |
| 暂停 / 继续 | Space |
| 单步并暂停 | S |
| 循环速度 1× / 2× / 4× / 快速 | F |
| 返回部署 / 重置当前场景 | R |
| 选择五类单位 | 1–5，仅部署时 |
| 山地 / 建筑 / 禁行区 | 6–8，仅部署时 |
| 切换红蓝方 | T |
| 保存场景 | Ctrl+S，仅部署时 |
| 加载已保存场景 | L，仅部署时 |
| 撤销 / 删除选中障碍 | Backspace / Delete |
| 清空单位与障碍 | C，界面确认后执行 |
| 显示 / 隐藏残骸 | K |

部署时左键点击放置单位；选择障碍类型后拖拽空白处创建矩形；拖动对象移动，拖动已选障碍右下角缩放。左键选中障碍后可用 Delete 或“删除选中障碍”删除；右键直接删除单位或障碍。地面单位受障碍和对象间距限制，失败时显示原因。

## 测试与打包

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m pip install pyinstaller
.\.venv\Scripts\python.exe -m PyInstaller --noconfirm UAV_WarGame.spec
```

Windows 推荐用 `powershell -ExecutionPolicy Bypass -File .\build_windows.ps1` 构建，脚本临时使用独立依赖搜索路径，打包配置排除其他工具可能带入的冲突 ICU 和系统运行库副本。它不会更改电脑的永久环境变量。

配置采用 PyInstaller 单文件模式，产物是 `dist/UAV_WarGame.exe`。QML、图标和预设场景随程序打包。发布前需在无 Python 的 Windows 电脑上验证真实显示缩放、文件对话框与用户目录权限。

2026-10-11 验证：405 项测试通过；源码与正式 EXE 的九组流程自检通过，涵盖五个场景、地图导航、时间修改、完整记录与摧毁时刻、持久化、运行和结算。四组固定随机种子的对战与修改前逐项一致。详细证据见测试报告。

`.github/workflows/verify.yml` 提供 Windows 自动测试；手动触发还会构建并保存 EXE。源码压缩包需要提交到自己的 GitHub 仓库后，工作流才会执行。

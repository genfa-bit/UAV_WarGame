## 按键说明

- `Enter`：部署阶段开始仿真。
- `M`：切换预设/手动部署。
- `1` 到 `5`：选择部署兵种。
- `T`：切换部署阵营。
- `鼠标左键`：放置当前选择单位。
- `Backspace`：撤销部署。
- `C`：清空手动部署。
- `Space`：暂停 / 继续仿真。
- `S`：单步推进一帧，适合逐步讲解侦察、集火和攻击。
- `R`：重置场景。
- `ESC`：退出程序。

## 演示流程

1. 启动程序，介绍地图、基地、障碍物和右侧信息面板。
2. 说明当前处于 Deployment / Preset，按 Enter 可使用预设开局。
3. 按 M 切换 Manual，说明当前阵营、当前兵种和右侧按键提示。
4. 用数字键选择兵种，按 T 切换阵营，鼠标左键放置红蓝双方单位。
5. 演示地面单位不能放入障碍物，空中单位可以部署在障碍物上方。
6. 按 Enter 开始仿真，观察探测范围和 `[Scout]` 控制台日志。
7. 继续推进，观察集火目标、攻击连线、血条变化和 `[Attack]` 日志。
8. 观察低血量或弹药耗尽单位进入 Evade，并远离敌人或撤向基地。
9. 等待一方单位全部摧毁，说明 Finished 状态和胜负结果。

## 攻击演示流程

1. 使用预设开局按 Enter 进入仿真。
2. 按 `S` 单步推进，直到右侧面板出现 `[Scout]` 发现日志。
3. 继续单步或按 Space 运行，观察攻击者和目标之间出现黄色短暂连线。
4. 观察目标位置的命中标记、血条下降和右侧统计中的攻击次数、总伤害增长。
5. 观察控制台和右侧面板中的 `[Attack]`、`[Destroyed]` 日志。

## 胜负判断演示流程

1. 使用手动部署模式放置少量单位，例如红方 1 辆高伤害无人战车、蓝方 1 架侦察无人机。
2. 按 Enter 开始仿真，使用 `S` 单步推进，便于观察每次攻击。
3. 当蓝方单位被摧毁后，右侧面板显示红方击毁数增加。
4. 蓝方剩余单位为 0 时，系统进入 Finished，右侧结果显示“红方获胜”。
5. 如需演示平局，可在测试中使用红蓝双方初始 `hp=0` 的用例，`pytest` 会验证 winner 为 `draw`。

## 答辩讲解要点

- 系统采用分层结构，核心逻辑和界面绘制解耦。
- 场景数据来自 JSON，新增场景不需要改主程序。
- 兵种通过 `unit_type` 和 `UnitFactory` 创建，新增兵种只需注册。
- 空中单位可越过障碍物，地面单位不能进入障碍物，指挥节点不移动。
- 单时间步流程集中在 `Simulator.step()`，顺序清晰。
- 侦察目标池按阵营区分，体现信息共享。
- 集火规则简单可解释：低血量优先，距离近优先。
- 规避规则体现自主性：低血量、无弹药、敌人过近都会触发。
- 战斗统计覆盖剩余单位、击毁数、攻击次数、总伤害和胜负结果。
- 最近 8 条战斗日志同时输出到控制台和右侧信息面板。
- pytest 测试覆盖核心业务规则。

## 常见问题

### Pygame 安装失败

请确认使用 Python 3.10-3.13 的 Anaconda 环境。Python 3.14 可能暂无稳定 Pygame 预编译包。

### VS Code 运行时找不到 pygame

请在 VS Code 中选择解释器：

```text
D:\Anaconda\envs\uav_wargame\python.exe
```

### 中文显示异常

系统默认使用 `Microsoft YaHei`，如果本机没有该字体，可在 `ui/panel.py` 和 `ui/renderer.py` 中替换为可用中文字体。

### 单位在障碍物附近移动不够智能

当前障碍物规避是基础版本，下一阶段可加入 A* 路径规划或更细粒度网格寻路。
## 第六阶段协同打击演示

1. 启动程序并进入预设部署，按 `Enter` 开始仿真。
2. 使用 `S` 单步推进，观察右侧信息面板中的“发现 红/蓝”和“红方集火 / 蓝方集火”。
3. 当侦察单位发现敌人后，控制台和右侧日志会出现 `[Scout]` 与 `[TargetPool]`，说明目标已进入阵营共享目标池。
4. 继续推进，观察 `[Focus] Red focus target changed to ...` 或 `[Focus] Blue focus target changed to ...` 日志。
5. 说明 focus 选择规则：先排除已摧毁目标，再按低生命值、高威胁值、距离己方平均位置更近排序。
6. 当 focus 目标被摧毁后，目标池会清理该目标，并重新选择新的集火目标。

验收讲解要点：

- `red_detected_targets` 和 `blue_detected_targets` 是阵营级共享目标池；
- `last_seen_step` 用于刷新和超时清理；
- 多个单位围绕同一个 `focus_target` 移动或攻击；
- 日志能够展示目标池变化和集火目标变化。

## 第六阶段战术规避演示

1. 使用预设场景或手动部署，让双方单位接近。
2. 运行仿真，观察地图上单位旁边的状态文字。
3. 当单位低血量、弹药耗尽、敌人过近或面对高威胁敌人时，状态会切换为 `Evade`。
4. 观察右侧信息面板中的“规避 红/蓝”和“规避单位”。
5. 规避单位会远离最近可见敌人；如果没有可见敌人，则向己方基地撤退。
6. 说明地面单位规避时仍受障碍物限制，空中单位可以越过障碍物。
7. 说明 `Evade` 状态下允许近距离自卫攻击，但不会主动追击，攻击后仍保持 `Evade` 状态。

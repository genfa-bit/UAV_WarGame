# v1.0 课程验收说明

默认验收 PySide6/QML 主程序。安装、启动和单文件打包命令以 [README](../README.md) 为准，鼠标操作及答辩步骤见 [操作手册](操作手册.md)。

## 核心验收过程

| 阶段 | 操作与预期 |
| --- | --- |
| 启动 | 主窗口、帮助、预设图标与中文正常 |
| 选场景 | 标准对抗、障碍环境、自定义场景、山区河谷、河谷城镇均可切换；自定义场景可部署 |
| 编辑 | 单位、障碍与基地可编辑；非法操作有说明，清空有确认 |
| 地图风格 | 部署阶段可选择战术、山谷、河谷；运行和暂停均拒绝更改 |
| 地图导航 | 滚轮 1–4 倍缩放、中键平移、放大后左键拖动平移（按下即移动）、− / + / 适应地图、右下小地图点击与拖动定位有效；平移不放置或移动对象 |
| 显示图层 | 网格、地标、全部范围可切换；显示切换不改变矩形障碍与仿真规则 |
| 保存 | 保存 / 另存为有提示；加载恢复 `map.style`，预设不被覆盖，加载失败保留原态 |
| 运行 | 开始、暂停、单步、速度选择与重置一致 |
| 时间设置 | 部署或暂停时可改单步秒数与最大步数，运行时禁用；已有累计时间不被重算 |
| 运行记录 | 分类查看侦察、共享、摧毁、战术和结果的步数与时刻；界面显示最近 200 条，导出保留全部 |
| 历史记录 | 暂停、结算、重跑及退出时保存独立文件，重启能读取历史摘要；失败记录保留并可重试 |
| 观察 | 点选高亮并实时显示详情，日志可筛选 |
| 结束 | 自动结算，红胜、蓝胜、平局正确，可以导出 |
| 复用 | 返回战场、重新运行、修改部署，可重复操作 |
| 回放 | 结算框“回放本局”、历史行“回放”、工具栏“载入回放…”三个入口均可进入，最后者在部署阶段也可用；回放条可播放/暂停、单步前后、拖动滑块定位、变速；运行记录与统计同步到游标；按 Esc 退出回到进入前的部署（从部署阶段进入时回到正在编辑的布局）且 `runs` 不多出文件；版本 2 旧记录按钮置灰并给出原因 |
| 交付 | 本机 EXE 自检能加载 QML、图标、两张底图和五个场景；无 Python 独立机启动另行人工验收 |

详细案例见 [优化工作流与验收清单](优化工作流与验收清单.md)。自动测试和本机运行结果见 [测试报告](测试报告.md)，尚未验证的环境不视为通过。

## 本轮证据（2026-10-11）

五个预设的风格依次为 `river / valley / tactical / valley / river`。前三个保持既有 800×600 世界尺寸；山区河谷和河谷城镇均为 1200×800，各 14 个单位、16 个障碍。图片只提供背景，实际通行依据高亮矩形障碍与兵种规则。Pygame 兼容入口未新增地图导航。

| 验证项 | 本机结果与证据 |

| 验证项 | 本机结果与证据 |
| --- | --- |
| 全量自动测试 | 460 项通过、0 失败、0 跳过；在 420 项基线上新增 40 项（回放核心 12、回放控制器 14、回放 QML 9、记录压缩与归档读写 5）；本轮未重新生成 [pytest XML](verification/pytest-results.xml)，该文件仍是 2026-10-11 的 405 项证据；[回放检查记录](verification/replay-checks.json)、[记录体积检查](verification/journal-size-checks.json) |
| 运行记录归档压缩 | 同一份 2000 步记录：缩进明文 8.80 MB → 紧凑 6.66 MB（−24%）→ 紧凑加 gzip 0.282 MB（−96.8%，31.3 倍）；逐帧回放内容一字未改，压缩后进入/寻址/退出回放与历史可回放检查仍通过；场景另存与用户导出仍写缩进明文；截断归档只影响该条记录 |
| 记录格式 | 运行记录由版本 2 升为 3，新增 `replay` 逐帧负载与 `map` 静态地图负载；版本 2 旧文件仍可读取与导出，但标记不可回放 |
| 编码与体积 | 每单位每帧 7 个 int16（位置 0.1 像素、生命、弹药、状态与交战码表下标、摧毁标志），交织后整体 base64；10 单位 2000 步原始约 274 KB、base64 后约 365 KB，小于同局 `records` 块 |
| 回放一致性 | 帧位置与实时状态一致（位置误差 < 0.05 像素）；攻击连线由该帧前后 7 步的交战记录与帧位置还原，与实时快照逐字段一致并在 7 步后过期；统计、运行记录、摧毁时刻与日志按游标过滤 |
| 回放只读 | 回放期间逐字节确认不新建或覆盖 `runs` 下任何文件；保存地图、返回部署、重新运行、载入地图与修改时间设置均被拒绝 |
| 退出回放的位置 | 从运行、暂停或已结束状态进入时回到本次运行前的部署；从部署阶段进入时回到当时正在编辑的布局（`reset()` 已清空 `_run_deployment`，不做处理会退回场景初始布局） |
| 回放界面 | 三个入口与回放条在 920×540、1280×720、1440×900 均在窗口内可点击；底部“载入回放…”在部署阶段可见可用，920×540 下仍在可视区内；Space / ← / → / Esc 快捷键通过；离屏截图 [回放第 0 步](verification/replay-1280x720.png) |
| 源码与 EXE 自检 | 源码自检 `ok=true`，检查由九组增至十组，新增 `replay_last_run_without_touching_journals`；[source-smoke.json](verification/source-smoke.json) 仍是 2026-10-11 的九组证据，本轮未重新生成 |

尚未验证：真实鼠标拖动进度滑块的连续手感，以及无 Python 的独立 Windows 电脑上的回放。离屏事件测试只覆盖 `moved` 信号与按钮点击。

# v1.0 课程验收说明

默认验收 PySide6/QML 主程序。安装、启动和单文件打包命令以 [README](../README.md) 为准，鼠标操作及答辩步骤见 [操作手册](操作手册.md)。

## 核心验收过程

| 阶段 | 操作与预期 |
| --- | --- |
| 启动 | 主窗口、帮助、预设图标与中文正常 |
| 选场景 | 标准对抗、障碍环境、自定义场景、山区河谷、河谷城镇均可切换；自定义场景可部署 |
| 编辑 | 单位、障碍与基地可编辑；非法操作有说明，清空有确认 |
| 地图风格 | 部署阶段可选择战术、山谷、河谷；运行和暂停均拒绝更改 |
| 地图导航 | 滚轮 1–4 倍缩放、中键平移、− / + / 适应地图、右下小地图点击与拖动定位有效 |
| 显示图层 | 网格、地标、全部范围可切换；显示切换不改变矩形障碍与仿真规则 |
| 保存 | 保存 / 另存为有提示；加载恢复 `map.style`，预设不被覆盖，加载失败保留原态 |
| 运行 | 开始、暂停、单步、速度选择与重置一致 |
| 观察 | 点选高亮并实时显示详情，日志可筛选 |
| 结束 | 自动结算，红胜、蓝胜、平局正确，可以导出 |
| 复用 | 返回战场、重新运行、修改部署，可重复操作 |
| 交付 | 本机 EXE 自检能加载 QML、图标、两张底图和五个场景；无 Python 独立机启动另行人工验收 |

详细案例见 [优化工作流与验收清单](优化工作流与验收清单.md)。自动测试和本机运行结果见 [测试报告](测试报告.md)，尚未验证的环境不视为通过。

## 本轮证据（2026-10-10）

五个预设的风格依次为 `river / valley / tactical / valley / river`。前三个保持既有 800×600 世界尺寸；山区河谷和河谷城镇均为 1200×800，各 14 个单位、16 个障碍。图片只提供背景，实际通行依据高亮矩形障碍与兵种规则。Pygame 兼容入口未新增地图导航。

| 验证项 | 本机结果与证据 |
| --- | --- |
| 全量自动测试 | 326 项通过、1 条第三方警告；[pytest XML](verification/pytest-results.xml) |
| 地图新增测试 | 28 项通过：17 项 [后端地图测试](../tests/test_terrain_maps.py)、11 项 [QML 地图测试](../tests/test_map_view_qt.py) |
| 新场景规则 | 基地、地面单位初始部署合法；独立网格洪泛验证双方基地、地面单位和两处桥梁通道连通 |
| 导航事件 | 本机离屏 Qt 鼠标 / 滚轮事件覆盖缩放、平移、小地图定位与恢复完整视图 |
| 源码与 EXE 自检 | 各六组均通过，覆盖五个场景；[源码自检](verification/source-smoke.json)、[EXE 自检](verification/package-smoke.json) |
| 新场景自动结算 | 山区河谷 / 河谷城镇各用种子 42、7，四次无异常，均到 2000 步上限平局；[运行记录](verification/map-scenario-runs.json) |

离屏截图：[标准对抗](verification/map-standard-1280x720.png)、[障碍环境](verification/map-obstacles-1280x720.png)、[自定义场景](verification/map-custom-1280x720.png)、[山区河谷](verification/map-valley-1280x720.png)、[河谷城镇](verification/map-river_city-1280x720.png)、[地图缩放](verification/map-zoom-1280x720.png)。素材来源与限制见 [地图与素材说明](地图与素材说明.md)。

四次上限平局证明场景可进入自动运行并有限结束，不代表这四次出现了自然胜负。截图和离屏事件测试也不能作为真实桌面操作或无 Python 独立机启动的验收结论。

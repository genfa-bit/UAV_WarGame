# v1.0 操作手册

## 一次完整演示

1. 启动 UAV_WarGame.exe，或在项目目录运行 python main.py。首次启动阅读帮助，之后可用底部“帮助”或 F1 重新打开。
2. 从五个预设中选择场景。“标准对抗”和“障碍环境”便于快速演示；“山区河谷”和“河谷城镇”展示更大的地图与桥梁通道；“自定义场景”从空白地图部署。
3. 在部署阶段按需选择“战术 / 山谷 / 河谷”地图风格，再选择阵营和兵种，点击战场放置。选择障碍类型后在空白处拖出矩形；拖动对象移动，拖动障碍右下角调整大小。
4. 点击“保存地图”保留部署。需要指定文件名时使用“地图另存为…”；成功信息显示文件名，之后可用“载入地图…”再次读取。
5. 按需打开“时间设置”，修改单步时长和最大运行步数，再点击“开始”。使用暂停、单步和 1×/2×/4× 观察过程。“快速计算”适合等待结果，动画只展示刷新时的状态；暂停时也可调整时间设置。
6. 点击地图单位，查看右侧详情和高亮探测范围。打开“运行记录”，按侦察、目标共享、摧毁、战术或结果分类，查看事件步数和累计仿真时间；可在运行、暂停或结束阶段导出 JSON。
7. 结束自动结算。查看剩余单位、击毁、攻击、命中、伤害及累计仿真时间，按需点击“导出战报…”导出包含完整事件与摧毁时刻的 JSON；也可点击“回放本局”把刚打完的这一局按帧重看。
8. “返回地图”保留结束状态；“再来一局”恢复本次初始部署再次启动；“调整部署”恢复开跑前部署供编辑。

默认单步时长 0.22 秒，最多运行 2000 时间步。部署或暂停时均可修改；暂停后的上限必须大于已运行步数。到上限仍未分胜负时结算平局，并说明原因；快速计算便于在答辩时间内展示完整过程。

“运行记录”界面显示最近 200 条，自动保存与导出保留完整事件。每局都有独立记录文件，重新运行不会覆盖上一局；自动保存目录是 `%LOCALAPPDATA%\UAV_WarGame\runs`。发生保存失败时界面给出提示，可手动导出到其他目录。详细字段、共享时刻的含义与保存时机见 [时间设置与运行记录](时间设置与运行记录说明.md)。

左键点击或拖动障碍会选中它，选中后可拖动右下角缩放，或点击“删除选中障碍” / 按 Delete 删除。右键点击可直接删除单位或障碍。

## 场景与地图浏览

| 预设 | 地图范围 | 初始风格 | 用途 |
| --- | --- | --- | --- |
| 标准对抗 | 800×600 | 河谷（`river`） | 保留原有 10 个单位、3 个障碍的对抗布局 |
| 障碍环境 | 800×600 | 山谷（`valley`） | 观察已有障碍布局中的地面绕行 |
| 自定义场景 | 800×600 | 战术（`tactical`） | 空白地图，自行部署 |
| 山区河谷 | 1200×800 | 山谷（`valley`） | 14 个单位、16 个障碍，含两处桥梁通道 |
| 河谷城镇 | 1200×800 | 河谷（`river`） | 14 个单位、16 个障碍，含城镇与桥梁布局 |

PySide6/QML 主界面提供以下导航：

| 操作 | 效果 |
| --- | --- |
| 地图上滚动滚轮 | 在 1–4 倍范围缩放 |
| 按住中键拖动 | 平移主视图 |
| 放大后按住左键拖动 | 平移主视图（按下即可移动，不影响放置与点选） |
| 左键按住约 0.3 秒后再拖动 | 按下处正在部署编辑时，改用平移主视图 |
| 点击“− / +” | 缩小或放大 |
| 点击“适应地图” | 恢复完整地图视图 |
| 点击或拖动右下角小地图 | 快速定位主视图 |
| 切换“网格 / 地标 / 全部范围” | 显示或隐藏对应图层 |

放大后可用中键、左键拖动或小地图查看其他区域，回到完整布局时点击“适应地图”。这些操作只调整观看位置，不移动单位或改变世界尺寸。地图风格仅能在部署阶段更改；运行和暂停阶段均不可更改。网格、地标和范围是显示选项，隐藏后碰撞与探测规则仍然有效。

左键平移按“这次按下有没有编辑语义”区分：运行态下按在哪里都是直接拖动平移；部署态按在空白处且未选障碍类型时也是直接拖动平移；只有按下处已经开始了编辑手势（选了障碍类型后拉框创建、拖动单位/障碍/基地、拖动已选障碍的缩放把手）时，才需要先按住不动约 0.3 秒再移动来改判为平移。改判后已经开始但尚未提交的创建或拖动会被放弃，松开鼠标不会落下对象。适应地图（1×）时地图不超出视口、没有可平移空间，左键拖动始终按原来的放置与编辑处理。

图片中的河流、道路和建筑用于展示；实际通行约束以高亮矩形障碍和兵种规则为准。Pygame 兼容入口未新增这些导航功能。底图来源和完整性见 [地图与素材说明](地图与素材说明.md)，界面示例见 [山区河谷](verification/map-valley-1280x720.png)、[河谷城镇](verification/map-river_city-1280x720.png) 和 [缩放视图](verification/map-zoom-1280x720.png)。

## 回放

每局运行记录都带有逐步的单位与基地状态，因此已保存的对战可以按帧重放。三个入口：结算对话框的“回放本局”（刚打完这一局）、“运行记录”历史行末尾的“回放”（任意一局）和底部工具栏的“载入回放…”（任意位置的记录文件，默认打开 `runs` 目录）。底部这个按钮在部署、运行、暂停和已结束状态都可用，刚启动程序就能看旧记录；回放进行中它会隐藏。

| 操作 | 效果 |
| --- | --- |
| 播放 / 暂停 | 按当前速度档位推进或停住 |
| 上一帧 / 下一帧 | 单步前后移动游标 |
| 拖动进度滑块 | 定位到任意一帧 |
| 1× / 2× / 4× / 快速 | 调整回放速度 |
| Esc / 退出回放 / 返回部署 | 回到本次运行前的部署 |

回放中“战局回放”侧栏显示记录名、总帧数、单步时长与当前步数，可切换残骸显示；点击单位查看它在那一帧的详情。“运行记录”面板与战场统计会同步到游标处，攻击连线由该帧前后的交战记录还原。回放只读取记录文件，不会新建或覆盖 `runs` 下的任何文件；回放期间保存地图、返回部署、重新运行、载入地图和修改时间设置都会被拒绝。从部署阶段进入回放时，退出后回到当时正在编辑的那份布局，刚改过的单位与障碍不会丢。版本 2 的旧记录没有逐帧数据，历史行会说明“旧版本记录，未包含逐帧数据，暂不支持回放”。细节见 [时间设置与运行记录](时间设置与运行记录说明.md#回放)。

## 保存与恢复

内置场景不会被覆盖。首次保存写入 Windows 用户目录 `%LOCALAPPDATA%\UAV_WarGame\scenarios\saved_map.json`；“另存为”可选择有写权限的文件夹。只在部署阶段保存，确保文件包含下一次开局所需的原始单位与地图。

保存的 JSON 包含 `map.style`，重新加载会恢复所选地图风格。旧文件没有该字段时使用战术风格。运行时重置恢复开跑前的布局，不会把受损单位或移动后的坐标当作新开局。切换场景和清空会替换当前部署，请先保存需要保留的内容。加载失败时原场景保留。

## 常见反馈

| 提示 / 现象 | 处理方法 |
| --- | --- |
| 双方需要至少一个单位 | 回部署，为红蓝双方各放置单位 |
| 放置位置非法 | 依据提示避开边界、地面障碍和已有对象 |
| 保存或加载失败 | 检查文件格式与目录权限，重新选择文件 |
| 快速模式动画不连贯 | 切换 1×，或暂停后单步观察 |
| 放大后看不到整个地图 | 点击“适应地图”，或用中键、左键拖动 / 右下小地图定位 |
| 左键拖动没有平移 | 检查是否处于适应地图（1×）缩放，此时没有可平移空间；若按下处已经开始部署编辑，需先按住不动约 0.3 秒再移动，或改用中键 |
| 左键拖动时地图跟不上光标 | 该现象来自按局部坐标计算增量，当前实现取场景坐标逐步跟随；若仍出现，记录窗口缩放与系统 DPI 设置供排查 |
| 运行或暂停时无法选择地图风格 | 回到“调整部署”后再选择风格 |
| 场景已结束，不能继续 | 重新运行，或返回部署修改布局 |
| 历史行的“回放”按钮置灰 | 该文件是版本 2 的旧记录，没有逐帧数据，只能查看与导出 |
| 回放时按钮点不动 | 回放中会临时禁用保存地图、返回部署、重新运行、载入地图与修改时间设置；先按 Esc 退出回放再操作 |
| 字体 / 缩放异常 | 调整窗口，记录分辨率与系统缩放供排查 |

## 5—7 分钟答辩

选择场景并展示缩放 / 小地图（30 秒）→ 编辑部署与障碍（1 分钟）→ 保存并重新加载（30 秒）→ 开始、暂停、单步与变速（1.5 分钟）→ 单位详情（30 秒）→ 结算、导出与回放本局（1.5 分钟）→ 展示测试报告和 EXE（1 分钟）。

截至 2026-10-10，地图功能已通过本机离屏 Qt 鼠标、滚轮事件与保存加载测试，完整证据见 [验收说明](验收说明.md)。真实桌面操作及无 Python 独立机启动仍需人工检查。

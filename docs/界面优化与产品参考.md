# 界面优化与产品参考

2026-10-11，本轮由 Astra 负责主界面设计与实现，在现有 PySide6/QML 前端上整理信息层级。目标是便于部署、观察和复盘，让地图成为视觉主体，减少装饰、重复边框和固定高度留白。

## 产品参考

| 产品与来源 | 可借鉴的设计原则 | 本项目的处理 |
| --- | --- | --- |
| [QGroundControl Plan](https://docs.qgroundcontrol.com/master/en/qgc-user-guide/plan_view/plan_view.html) / [Fly](https://docs.qgroundcontrol.com/master/en/qgc-user-guide/fly_view/fly_view.html) 官方指南 | 地图、操作、状态和计划编辑各有明确位置，按工作阶段提供相关工具 | 部署工具与运行观察分阶段显示；地图工具合并为一行，播放操作集中在底部 |
| [Command: Modern Operations 官方 UI 设计说明](https://command.matrixgames.com/?p=4954) | 深色工作区、简化工具栏、可收起的信息区域，以及按类别组织消息 | 缩小侧栏，把统计卡片整理为对齐的数据行；记录仍在独立弹窗按类别查看，避免占满地图 |

QGroundControl 属于无人机地面站，用于参考地图操作与信息分层。CMO 属于兵棋仿真；这里引用的是其 2019 年公开设计说明，不把文章截图当作 2026 年最新版界面。以上为官方公开资料的研究，未进入这些产品的实际运行环境，也不作功能或可用性的全面测评。

## 视觉与布局

- 统一石墨灰工作区和低饱和青绿主操作色，红蓝用于阵营和必要结果提示。
- 标题栏 52 px、地图工具栏 40 px、播放栏 52 px；侧栏按窗口宽度为 288–312 px。
- 全界面统一使用内置思源宋体（Source Han Serif CN），包括正文、数字、输入、统计、地图标签与弹窗；常规和粗体分别使用官方 OTF，不依赖系统安装。来源与许可证见 [字体记录](../ui/assets/fonts/sources.json)。
- 常规按钮 32 px，圆角 4–6 px；正文 12 px，页面标题 16 px。主操作采用填充色，选中与键盘聚焦单独表达。
- 取消大英文装饰标题、背景渐变、整块阵营描边与六张重复统计卡片；单位详情随内容自适应高度。
- 地图标题显示当前场景名称；网格、地标、范围开关及地图坐标逻辑保留。卫星图网格、小地图视窗和地标底色收敛到同一视觉体系。
- 场景文件操作合并为紧凑一行，单位与障碍工具保持可直接访问；较长侧栏仍可滚动，键盘聚焦会把目标控件滚动到可见位置。

主题集中在 `ui/qml/Theme.js`，主界面和支持面板共同使用，避免各页面分别维护颜色、字号和圆角。

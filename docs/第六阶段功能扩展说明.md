# 第六阶段功能扩展说明

## 1. 本阶段目标

第六阶段围绕“自主侦察、协同打击、战术规避”进行增强，在不推翻前面阶段成果的前提下，补强共享目标池、集火目标选择、兵种行为差异、规避状态机、UI 展示、测试和验收说明。

## 2. 共享目标池设计

新增 `core/target_pool.py`，每个阵营维护一个 `TargetPool`：

- 红方目标池：`red_detected_targets`
- 蓝方目标池：`blue_detected_targets`
- 目标记录：`TargetSighting(target, last_seen_step)`

侦察阶段中，单位发现敌人后调用 `TargetPool.sight()` 写入本阵营共享目标池。如果目标已存在，则刷新 `last_seen_step`；如果目标首次出现，则记录 `[TargetPool]` 日志。每个时间步会清理已摧毁目标和超过 `DETECTION_TIMEOUT_STEPS` 未再次发现的过期目标。

## 3. 协同打击规则

每个阵营从共享目标池中选择一个 `focus_target`。单位存在集火目标时优先围绕该目标行动：

- 在攻击范围内：优先攻击 `focus_target`
- 不在攻击范围内：向 `focus_target` 机动
- 无 `focus_target`：执行侦察、巡逻或向敌方区域推进

集火目标变化时输出日志：

```text
[Focus] Red focus target changed to Blue missile vehicle 1
```

## 4. focus_target 选择算法

选择优先级如下：

1. 排除已摧毁目标；
2. 生命值最低优先；
3. 生命值相同时，威胁值最高优先；
4. 仍相同时，距离己方平均位置更近优先；
5. 如果仍相同，保留任意稳定选择。

伪代码：

```text
candidates = not destroyed targets in detected_targets
avg_position = average position of active friendly units
sort candidates by:
    hp ascending
    threat_value descending
    distance(target, avg_position) ascending
return first candidate
```

## 5. 威胁值设计

当前威胁值配置在 `config.THREAT_VALUE_BY_TYPE`：

| 兵种 | threat_value |
| --- | --- |
| ScoutDrone | 2 |
| StrikeDrone | 4 |
| GroundVehicle | 5 |
| MissileVehicle | 6 |
| CommandNode | 8 |

`Unit.threat_score` 目前直接返回 `threat_value`，后续可以扩展为综合火力、弹药、生命值和通信价值的动态评分。

## 6. 兵种协同行为差异

- `ScoutDrone`：优先侦察和刷新目标池，不主动冲入近距离攻击；目标过远时才向目标方向靠近。
- `StrikeDrone`：优先攻击 `focus_target`，适合作为机动打击单位。
- `GroundVehicle`：作为正面推进单位，按共享目标推进和攻击，地面移动受障碍物限制。
- `MissileVehicle`：优先保持距离，在远程范围内攻击，目标过近时拉开距离。
- `CommandNode`：不主动移动，可作为目标共享逻辑中心；本阶段暂不实现通信范围，后续可扩展为有通信半径的指挥节点。

## 7. 战术规避规则

单位满足以下任一条件时进入 `Evade`：

- `hp / max_hp < 0.3`
- `ammo == 0`
- 最近敌人距离小于危险距离
- 对方火力威胁明显高于本单位且处于威胁范围内

危险距离定义为：

```text
danger_distance = max(50, enemy.attack_range * 0.5)
```

规避行为：

- 有可见敌人时，向远离最近敌人的方向移动；
- 没有可见敌人时，向己方基地撤退；
- 地面单位调用 `try_move()`，不会进入障碍物；
- 空中单位可越过障碍物；
- `MissileVehicle` 优先保持远程距离；
- `Evade` 状态下允许近距离自卫攻击，但攻击后仍保持 `Evade` 状态。

## 8. 单位状态机设计

状态规范为：

```text
Scout -> Move -> Attack
          ^        |
          |        v
        Evade <- Threat / low hp / no ammo
Destroyed 为终止状态
```

时间步状态更新规则：

1. `Destroyed` 单位不再行动；
2. 低血量、无弹药、敌人过近或高威胁时进入 `Evade`；
3. 有目标且在攻击范围内进入 `Attack`；
4. 有目标但距离不够进入 `Move`；
5. 没有目标时进入 `Scout` 或巡逻推进。

# 地图与素材说明

本轮在现有 Python、PySide6/QML 仿真项目内复用两张本地参考地图，保留当前控制器、仿真内核和矩形碰撞路径。复用范围为图像素材及来源说明，没有迁入参考项目 `Exp` 的程序代码、瓦片加载系统、单位模型或地图运行配置。

## 1. 素材来源与完整性

用户已授权复用本地“应用综合实验”参考项目 `Exp/sim_app/assets` 中的地图。两个源文件均原样复制，源文件和参考项目代码未作修改；没有新图生成、裁剪、像素编辑、插值或预先缩放。运行界面可根据地图和视口大小渲染原图。

| 用途 | 本项目文件 | 参考项目内的相对路径 | 源图与复制图尺寸 | 字节数 |
|---|---|---|---|---|
| 山区河谷底图 | `ui/assets/maps/terrain_valley.png` | `sim_app/assets/terrain_astra/terrain_astra.png` | 1536×1024 | 4,239,699 |
| 河谷城镇底图 | `ui/assets/maps/terrain_river.png` | `sim_app/assets/illustrated/terrain.png` | 1536×1024 | 4,123,235 |

完整来源、SHA256、源图尺寸、复制图尺寸及用途记录在 [sources.json](../ui/assets/maps/sources.json)。已核对每个复制文件与原文件的 SHA256 完全一致：

参考来源说明如下，均来自本地参考项目的随附资料：

- `sim_app/assets/terrain_astra/README.md`：1536×1024 原始图像是二维视觉背景，不承担高程、道路通行或碰撞计算，没有真实经纬度绑定。
- `sim_app/assets/terrain_astra/landmarks.json`：虚构区域；地标来自人工视觉标注，道路点线是展示近似，不能当作测绘路网。其原项目 12000×8000 世界坐标没有直接迁入本项目。
- `sim_app/assets/illustrated/README.md`：`terrain.png` 为小范围虚拟山谷底图，图片不提供真实地理坐标或通行规则。
- `sim_app/assets/illustrated/asset_sources.json`：记录 `terrain.png` 为 2026-10-04 的参考引导图像生成素材；山区河谷来源记录为 2026-10-06。它们是参考项目的既有图像，本轮没有重新生成。

## 2. 地图尺寸与视觉图层

新增地图的仿真范围为 **1200×800**，两张原图保持 **1536×1024**，纵横比均为 3:2。渲染时完整映射到地图范围，图像文件本身仍保留所有原始像素；继续放大只会放大已有细节，不增加真实影像分辨率。既有三个场景保持 800×600 世界尺寸，图片按对应地图范围显示。

| 场景 | 预设 ID | `map.style` | 地图范围 | 底图 |
|---|---|---|---|---|
| 标准对抗 | `standard` | `river` | 800×600 | `terrain_river.png` |
| 障碍环境 | `obstacles` | `valley` | 800×600 | `terrain_valley.png` |
| 自定义场景 | `custom` | `tactical` | 800×600 | 战术网格，无图片底图 |
| 山区河谷 | `valley` | `valley` | 1200×800 | `terrain_valley.png` |
| 河谷城镇 | `river_city` | `river` | 1200×800 | `terrain_river.png` |

五个预设已接入主界面和打包程序。标准对抗保留原有 10 个单位、3 个障碍；山区河谷和河谷城镇各有 14 个单位、16 个障碍。两个新场景按图片近似布局设置矩形约束，并为桥梁预留通道。基地和地面单位初始位置通过部署规则校验，双方基地、地面单位和两处桥梁之间的连通性通过独立网格洪泛测试。

部署阶段可选择“战术 / 山谷 / 河谷”视觉风格，分别对应 `tactical`、`valley`、`river`。风格写入 JSON 的 `map.style`，保存再加载保持一致；旧地图缺少此字段时默认战术风格。运行和暂停阶段均拒绝更改。风格切换改变底图和地标展示，实际单位与障碍配置继续保留。

若需要参考原图上的地标位置，本项目地图坐标使用左上角原点，X 向右、Y 向下。1200×800 地图与原图像素的映射为 `x = pixel_x × 1200 / 1536`、`y = pixel_y × 800 / 1024`，即两个方向均乘以 0.78125。参考项目原有道路、桥梁和地标位置只是显示参考，不会据此建立新的通行算法。

## 3. 图片与实际通行约束

底图中的山地、森林、河流、桥梁、道路、屋顶和机场细节用于视觉展示。图片不是高程模型、碰撞网格、河流边界或可自动识别的路网。

实际通行和碰撞沿用本项目的场景矩形障碍及单位规则。地图中高亮的矩形区域才是对应通行约束的依据；仅看底图上的河岸、桥梁或建筑轮廓不能判断是否可通过。地标标签、网格和探测范围属于显示图层，切换其可见性不改变仿真地图的障碍配置。

部署校验、单位运动、探测与攻击、统计、结束和重跑继续由本项目当前核心路径处理。视觉素材的接入没有将 `Exp` 中的道路或地形计算逻辑迁入本项目。

## 4. 主界面浏览功能与前端范围

地图浏览增强面向 **PySide6/QML 主界面**，已完成以下操作：

| 操作 | 行为 |
|---|---|
| 在地图上滚动鼠标滚轮 | 在 1–4 倍范围缩放视图 |
| 中键按住并拖动 | 平移地图视图 |
| 点击“− / + / 适应地图” | 缩小、放大或恢复完整地图视图 |
| 点击或拖动右下角小地图 | 将主视图定位到相应区域 |
| 切换“网格 / 地标 / 全部范围” | 显示或隐藏相应图层 |

导航只改变视口，不改变地图世界坐标、部署位置或碰撞规则。操作入口与步骤见 [操作手册](操作手册.md)。

Pygame 保持兼容旧界面，本轮没有为该入口新增缩放、平移或小地图导航。素材文件和地图风格数据采用共享核心路径，两套前端的地图展示与导航功能不完全一致。

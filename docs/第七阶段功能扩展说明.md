# 第七阶段功能扩展说明

## 概述

第七阶段目标为"场景编辑与界面体验增强"，重点提升仿真系统的可视化表现、场景编辑能力和用户交互体验，不修改协同打击、战术规避、目标池和状态机等核心逻辑。

完成时间：2026-05-31

---

## 一、单位销毁显示增强

### 功能说明
- 单位被摧毁后默认显示灰色半透明残骸
- 按 `K` 键切换残骸显示/隐藏
- 战斗进行中和结束后均可切换
- 不影响胜负判断、攻击逻辑和统计数据

### 实现
- `Simulator` 新增 `show_wrecks` 属性（默认 `True`）
- `Renderer._draw_units()` 根据 `show_wrecks` 决定是否绘制 Destroyed 单位
- 残骸使用灰色 + alpha 透明度渲染
- 主循环 `handle_runtime_key` 中响应 `K` 键

---

## 二、障碍物编辑功能

### 功能说明
- 在地图编辑模式下，鼠标左键拖拽创建矩形障碍物
- 实时显示半透明预览框
- 点击已有障碍物可选中（金色边框高亮）
- 拖拽选中障碍物可重新调整位置
- 按 `Delete` 或 `Backspace` 删除选中障碍物
- 宽度或高度小于 12px 的障碍物自动忽略
- 障碍物不能创建在地图边界外

### 实现
- 新增 `core/obstacle_editor.py`，包含 `MapEditor` 类
- `EditorState` 数据类管理创建/选中/拖拽/基地拖动状态
- 障碍物操作直接修改 `Battlefield.obstacles` 列表
- 新增 `GAME_EDITING` 系统状态

---

## 三、基地拖动编辑功能

### 功能说明
- 红方基地和蓝方基地均可拖动
- 鼠标点击基地圆形标记即可开始拖动
- 实时显示移动效果
- 基地不能移动到地图外（自动裁剪）
- 与障碍物编辑互斥

### 实现
- `MapEditor` 类中 `start_drag_base`/`update_drag_base`/`finish_drag_base` 方法
- 命中半径为 20px
- 直接修改 `Battlefield.red_base` 和 `Battlefield.blue_base`

---

## 四、地图保存与加载功能

### 功能说明
- 编辑模式下按 `Ctrl+S` 保存当前地图
- 部署阶段或编辑模式下按 `L` 加载地图
- 保存内容包括：障碍物布局、红蓝基地位置、单位部署
- 兼容现有 JSON 场景格式

### 实现
- 新增 `core/map_persistence.py`
- `save_scenario()` 序列化战场和单位为 JSON
- `load_scenario_file()` 复用 `scenario_loader.load_scenario()`
- 保存文件路径：`data/saved_map.json`

## 六、全屏显示支持

### 功能说明
- 按 `F11` 切换全屏/窗口模式
- 使用 `pygame.FULLSCREEN | pygame.SCALED` 保持逻辑分辨率
- 切换后所有功能正常（仿真、部署、编辑）

## 七、UI 显示优化

### 功能说明
- 部署阶段面板显示"当前模式"（预设部署/手动部署）
- 运行阶段面板显示"残骸显示"状态（开启/关闭）
- 编辑模式面板显示障碍物数量、基地坐标、操作提示
- 操作反馈消息："正在创建障碍物..."、"地图保存成功" 等

### 键盘操作更新

| 按键 | 功能 |
|------|------|
| Enter | 开始仿真 |
| M | 切换预设/手动部署 |
| E | 进入/退出地图编辑模式 |
| K | 切换残骸显示 |
| F11 | 全屏切换 |
| L | 加载地图 |
| Ctrl+S | 保存地图（编辑模式下） |
| Delete | 删除选中障碍物（编辑模式下） |
